# 介面重新設計：功能去留表

2026-11-13 盤點四個頁面的全部功能。原則：2000 年代淡藍復古**視覺**整個丟掉；功能只在明顯沒用時才拿掉，不確定的保留。API、資料邏輯、匯入格式都不變，下表只描述介面。

- **留**：有實際用途或獨特的小功能，照原行為保留，只換外觀。
- **合併**：功能保留，但和另一個重複入口併成一個。
- **拿掉**：只拿掉介面元素；底層 API 仍在，日後可以再接回。

## 拿掉的項目與理由

1. **首頁三個入口門**（我的電影／記下心情／我的網摘）：側欄導覽有一模一樣的連結。
2. **英文眉標**：繁中介面中只是裝飾，螢幕閱讀器還會念出來。
3. **頁尾標語**：裝飾文案，沒有資訊。

右欄「功能選單」、「你的帳號」卡、「匯入紀錄 ↗」等重複入口改成合併，不算拿掉。

## 另外修正：RSS 下載快取

`src/ui/portal.ts` 的「下載私人書籤 RSS」原本每次都重新抓 `/api/portal/feed`，而且沒有逾時設定。改成：

- 同一個登入憑證、收藏沒有變動時，重用上次下載的內容；
- 送出任何寫入請求（新增、編輯、刪除、匯入、復原）後清掉快取；
- 加上 20 秒逾時與 `redirect: "error"`，和其他 API 呼叫一致。
