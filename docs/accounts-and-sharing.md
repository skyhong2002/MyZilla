# 帳號、興趣、朋友與分享

## 第一次使用

開啟 `/community.html`（「帳號與朋友」）。既有使用者先以原始存取金鑰開啟，再填寫帳號、顯示名稱及至少 12 字元密碼建立擁有者帳號。既有所有歷史直接屬於此私人空間，不搬動、不重匯。之後可用帳號密碼登入，再切換至儀表板。

目前為本機帳號、邀請制；沒有 Google OAuth、電子郵件驗證或自助忘記密碼寄信。請保存密碼及原始擁有者金鑰，該金鑰繼續保有擁有者存取權。

擁有者可產生七天有效、只能使用一次的加入邀請碼。朋友在登入頁展開「收到加入邀請？建立帳號」，使用邀請碼建立自己的空白私人空間。加入本站不會自動成為朋友或公開資料。

每人從帳號頁產生自己的同步金鑰，填入擴充功能或 native importer。同步金鑰有效一年，可匯入及讀取本人的瀏覽紀錄；不能建立邀請、朋友、配對或分享。更換／撤銷會使舊同步金鑰立即失效，每帳號同時一把，所有裝置共用，輪替後須各自更新設定。既有原始擁有者金鑰不受同步金鑰輪替影響。

## 興趣分析

分析本人的全部造訪，依明列的網域規則分為科技、學習、文化、娛樂、生活、運動、購物或未分類。不讀取網頁正文、不呼叫外部模型、不推論人格或敏感特徵。複合內容網站只能先用粗略分類，未知網站維持未分類。可搜尋任何已匯入網站、逐站修正或恢復規則；列表逐批顯示，沒有總網站數截斷。

分析為請求時計算，使用造訪次數而非前景時間。目前没有 AI 語意模型、背景分析工作佇列、跨期間興趣變化或自訂分類名稱；不能把結果當成 urtube 影片主題分析的等價精度。

## 朋友與配對

用對方的精確帳號送出邀請。收到者可以接受或婉拒，送出者可以取消，任一方可以移除朋友。沒有公開使用者或瀏覽目錄。

帳號設定的「讓已接受的朋友比較我的興趣分類摘要」預設關閉。只有已接受朋友關係，且雙方都開啟，才會產生比較與開放分類摘要。任一方關閉或移除朋友會立即停止新的摘要存取。

配對用已分類造訪次數的餘弦相似度（0–100），排除未分類；任一方完全沒有分類資料時顯示資料不足，不捏造分數。只比較已接受的朋友，沒有全站陌生人推薦或私人歷史搜尋。

朋友可見名稱、分類計數與比例、總造訪數、摘要產生時間；看不到網址、標題、設定檔、裝置及個別造訪時間。

## 分享

先在興趣頁確認分類，再選 1／7／30 天有效期，主動建立摘要連結。分享儲存當時名稱與分類統計的固定快照；後續分類修正、名稱變動或新造訪不會改變已建立的分享。原始網址、標題、網站清單與來源不寫入分享快照。

任何持有連結的人都能閱讀摘要。連結使用不可預測隨機值，伺服器只儲存雜湊，不出現在公開目錄，回應要求 noindex 與 no-store。建立時複製保存完整連結；管理頁只列有效分享及到期時間，可逐筆撤銷。到期或撤銷後回傳 404。關閉朋友比較不會撤銷先前主動建立的分享，須在分享頁另行撤銷。已被收件者另存的內容無法收回。

## 隔離與認證

- 原始擁有者歷史仍在既有 `events` 表。每個新帳號使用 `account_events_<伺服器產生的 UUID>` 表；HTTP 身分驗證決定 Repository，不接受客戶端指定帳號或資料表。
- 帳號／朋友／分類修正／憑證／分享表與各帳號歷史都位於同一 SQLite 檔案，一次 SQLite backup 即包含全部帳號。帳號表名在資料層採固定白名單格式驗證。
- 密碼採每人隨機 salt 與 Node scrypt 衍生。Session、同步金鑰、邀請碼與分享連結只存 SHA-256 雜湊；分享內容只存允許的摘要。
- 網頁 session 有效七天，放在 sessionStorage，以 Bearer 傳送。登出及儀表板鎖定撤銷當前 session；密碼變更撤銷該帳號所有 session。沒有 cookie 認證。原始部署金鑰需透過部署設定另行輪替。
- 登入與註冊的 body 限制 8 KiB，單程序每分鐘最多 30 次 auth 嘗試、同時最多 4 次密碼衍生。正式目前單一程序；多副本部署前應改用共享限流。
- `/api/*` 仍全數要求認證。公開入口只有靜態頁面／下載、健康檢查、受限的登入／邀請註冊，以及使用者主動建立的 `/share/:token`。
- 新表為新增式初始化；不修改既有 event JSON、ID、來源或匯入契約。純 ingest 模式也會依帳號選擇資料表，不開放帳號與社交管理路由。

## 驗證

`npm test` 驗證帳號隔離、相同來源 ID 在不同帳號的匯入及重播、擁有者接管、單次邀請、憑證撤銷、雙方同意、移除朋友、分享過期／撤銷、HTML escape 與公開登入限流。

`npm run test:community` 以獨立暫存資料庫與兩個 Chromium 工作階段完成：建立擁有者、邀請註冊、登入、同步、朋友接受、相似度、分類修正、分享／撤銷及手機版面。測試不建立正式帳號、不對正式資料開啟配對或產生公開分享。
