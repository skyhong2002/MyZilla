# 舊 MyZilla 概念與新版對照

本次以 2007 年存檔的簡潔個人入口為參考，重新實作功能，不使用舊站帳號、資料或 PHP 程式，也不宣稱為原站營運延續。

研究來源：

- [2007-07-14 主頁](https://web.archive.org/web/20070714011435/http://myzilla.tw/myzilla.php)：取得原始 Big5 HTML；同時取回 2007-02-24 CSS 與 2007-03-01 Logo 作為版面研究。
- [2007-12-12 網址入口](https://web.archive.org/web/20071212234416/http://myzilla.tw:80/myzilla.php?block=mytiny)：訪客存檔保留功能選單，未包含登入後私人清單。
- [2008-04-13 電影頁](https://web.archive.org/web/20080413184018/http://myzilla.tw:80/myzilla.php?function=mymovies&imdb=tt0059742)：可確認評分、觀看、願望與收藏概念。
- [MyZilla Wiki 首頁](https://myzilla.wikidot.com/)：區分 MyZilla、MyURL、MyBlog、mood 與其他相關專案。

| --- | --- |
| 簡潔個人入口 | `/`：淡藍底、置中內容、橫向導覽、右側功能欄；手機提供上方快速切換。回顧與帳號頁也使用淺色系。 |
| 個人設定、登入註冊 | 延用 `/community.html` 的私人帳號、邀請制、同步金鑰及個人設定。 |
| 我的網址、新網址輸入 | 新增／修改／刪除標題、網址、筆記；全部帳號隔離，預設私人。 |
| 生活分類 | 個人、家庭、朋友、研究、工作；可搭配搜尋、標籤及排序。 |
| 點閱次數、最近使用 | 收藏開啟計數與最近開啟時間；另支援新加入排序。此計數不混入瀏覽器原始造訪資料。 |
| 上／下 20 項 | 收藏及搜尋記錄每頁 20 筆，沒有總筆數截斷。 |
| 多站快速搜尋 | 13 個搜尋入口：Google／Google 台灣、Scholar、Yahoo、IMDb、博客來、巴哈姆特、字典、PHP、MySQL、Amazon、eBay、Wikipedia。 |
| 搜尋記錄 | 保存由入口送出的引擎、關鍵字、次數、最後使用時間；再次搜尋或逐筆刪除。只有本人可讀。 |
| MyURL 可管理轉址 | 每個有網址的收藏可主動建立 1／7／30 天有效連結、查看開啟數、撤銷；修改收藏會更新目的地。 |
| 瀏覽記錄 | `/dashboard.html#history` 保留所有瀏覽器歷史、全量搜尋與分頁；安全的 HTTP/HTTPS 頁面可帶入新增收藏表單，使用者儲存後才加入。 |
| 看他人網址 | 內容來源切換「朋友分享的收藏」，只讀取已接受朋友明確設成朋友可見的項目。 |
| 線上使用者 | 主動勾選在線顯示後，最近五分鐘開啟入口的帳號會出現在站內名單；預設關閉，名單僅登入者可見。 |
| 電影清單 | 我的電影支援片名、參考網址、0–10 評分、觀看次數、願望、收藏媒體、筆記與朋友可見性。朋友觀影概況統計自己與已分享同片的朋友之評分、觀看、願望及收藏；以相同參考網址（未填網址時用相同片名）比對，每人取最新一筆。用 IMDb 入口搜尋後可自行加入，沒有偽造第三方電影資料庫。 |
| 網摘、RSS | 我的網摘保存文章網址與筆記；私人 RSS 匯出涵蓋全部網址和網摘，可下載或由帶 Bearer 驗證的客戶端讀取。 |
| 心情與歷史 | 我的心情保存心情、標題、筆記與建立時間，可搜尋、分頁、編輯及選擇朋友可見。 |
| 功能選單模式 | 基本／搜尋／電影／進階／工具模式快速切換對應入口；完整選單持續可用。 |
| 標籤整理 | 收藏手動標籤及搜尋，尚不宣稱重現當年 Wood 的自動化演算法。 |
| 資料攜出 | 全部收藏 JSON 匯出／匯入；逐筆接受／拒收結果，失敗明細下載。相同 ID 在同帳號更新，不重複新增；沒有總匯入列數上限。 |

## 分享與資料邊界

朋友可見的收藏包含該筆標題、網址、生活分類、標籤、筆記／影評、收藏欄位與使用統計，表單會明示。改回私人或移除朋友後立即停止讀取。分享收藏不代表分享原始瀏覽歷史、搜尋記錄或其他私人項目。

MyURL 連結是獨立的明確分享：持有者可以轉址到該收藏的網址，即使收藏列表設為私人。修改可見性不會自動撤銷已建立的 MyURL，請在短網址頁撤銷；刪除收藏會一併撤銷。其餘筆記不隨轉址公開。完整連結只在建立當下顯示，資料庫僅保留 token 雜湊。摘要分享繼續使用既有 `/share/` 機制，兩者分開管理。

搜尋只在使用者按下送出後導向所選外站，沒有伺服器代抓內網或第三方頁面。部分第三方網站會對自動化連線回傳 403，實際結果受該網站限制；自動化測試驗證網址組成與本地記錄流程，不宣稱能突破外站限制。原站已停用／無法確認的 Linkist、YahooBid 等入口不放置失效按鈕。

JSON 匯入保留內容、ID、評分、收藏與可見性設定，會以目前時間記錄匯入／更新；不覆蓋既有點閱計數、不還原短網址與帳號密碼。全量瀏覽器 SQLite 匯入流程沒有改動。RSS 與 JSON 是私人資料檔，下載後請依自己的需求保管。

## 無法宣稱已完整復原的部分

Wayback 未保存登入後所有表單、私人資料或原始程式。上表是有證據支持的概念重新實作，並非像素級或逐項行為一致的復刻。原站 Logo 僅用於研究；正式頁面使用重新繪製的 SVG，延續藍紫漸層、雙尖峰與橫向條紋概念，並搭配新版文字標誌。首頁、回顧、帳號頁與分頁圖示共用 `public/myzilla-mark.svg`，不直接使用原始 GIF。

Wiki 提及的部落格觀察全網排行、Door referral 追蹤、Wood 自動標籤與 Doom 規劃中遊戲屬相鄰專案；目前沒有來源資料與可確認的完整規格，因此未把它們包裝成已完成。電影跨站 metadata、全站陌生人影評統計、匿名陌生人搜尋紀錄，以及自動公開舊資料也未加入。

## 實作與維運

`src/portal/model.ts` 定義收藏契約與搜尋入口；`src/portal/routes.ts` 管理帳號範圍查詢、搜尋、分享、RSS；`src/ui/portal.ts` 為入口操作。新增 `portal_*` 資料表均在原 SQLite 檔案內，一次一致性備份涵蓋全部資料。既有 `events` 與各帳號歷史表不修改。

網頁回顧移到 `/dashboard.html`；擴充功能建置仍把回顧頁複製為擴充功能 `index.html`，不影響既有同步設定。`npm run test:portal` 在暫存資料庫驗證完整入口流程，正式資料不作測試 fixture。
